# Search using searchbar

By default the search bar uses your browser's own search engine.

![The search bar at the top of the new tab](../../../images/en/tips/use-searchbar/searchbar-location_1x.webp)

![The search bar with its search engine button](../../../images/en/tips/use-searchbar/searchbar-detail_1x.webp)

If you want to use another supported search engine (Google, DuckDuckGo or Bing), just choose one from the dropdown next to the search bar.

![The search engine dropdown next to the search bar](../../../images/en/tips/use-searchbar/searchbar-change_1x.webp)

This setting is not synchronized; it is remembered only in the browser where you set it.
