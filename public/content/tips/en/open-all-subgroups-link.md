# Open all links from subgroup at once

All the links in a subgroup can be opened at once, using the double arrow button next to the subgroup title and description. They open in a new tab group.

The subgroup's menu (three dot icon) also offers "Open all links in grouped tabs".

And it is possible to set up catching individually opened links from subgroup into tabs group too: 
[Catch links from subgroup into tab group](subgroup-links-into-tab-group.md)
