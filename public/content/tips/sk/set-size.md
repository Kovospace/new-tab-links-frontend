# Nastavenie veľkosti všetkého

Veľkosť prvkov rozhrania nastavíte v nastaveniach rozšírenia: v sekcii „Vzhľad a správanie“ posúvajte posuvník „Veľkosť“, kým nebude všetko tak, ako chcete.
